# Electrical Setup – Hydroelectric Power Generator

## 1. Electrical Components
- 12V Dynamo
- Connecting wires
- LED
- Multimeter

## 2. Working Principle
The dynamo converts mechanical energy received from the turbine into electrical energy.

## 3. Electrical Output
The generated voltage will be measured using a multimeter.

## 4. Testing Procedure
1. Rotate the turbine using flowing water.
2. Allow the belt to drive the dynamo.
3. Measure the output voltage.
4. Record the measured values.
5. Test the LED using a suitable circuit.

## 5. Safety Precautions
- Keep electrical connections dry.
- Check wire connections before testing.
- Use a suitable LED resistor.
- Avoid short circuits.
